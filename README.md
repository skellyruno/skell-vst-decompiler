# Skell VST Decompiler

Private, read-only binary-analysis laboratory for studying **user-provided** audio-plugin executables and designing **original** Skelliere DSP.

The repository is being initialized as a reproducible analysis tool. It is **not** a vendor source-code decompiler and does not bypass copy protection, activation, or licensing. Never commit third-party VST3 binaries, extracted source, private user audio, credentials, or font binaries.

All substantial development belongs in a feature branch and draft PR. Every finding must cite a source binary hash, native RVA, instruction/data evidence, and a confidence status. A model equation is not a verified plugin-render result.
