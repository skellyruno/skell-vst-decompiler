# Public DSP architecture observations and independent probes

Read 2026-11-24. Current manufacturer documentation is behavioral evidence, not confirmation of the exact archived binary build.

- FG-Stress (https://docs.slatedigital.com/VMR/FG-Stress.html): documented stereo link combines channels before detector; detector filter choices are distinct from audio path filtering and harmonic modes. Fixed threshold / external sidechain gain behavior. Compare in-phase, polarity-inverted, quadrature, left-only and asymmetric tones to distinguish pre-detector mixing from energy aggregation. Mean is a test hypothesis, not a confirmed normalization. Use coherent harmonics to separate even/odd coloration, not infer internal waveshaper.
- FG-2A (https://docs.slatedigital.com/VMR/FG-2A.html): documentation describes linked shared reduction based on an average, separate high-frequency sidechain sensitivity, variable threshold and limit/compress control. Exact averaging domain and times unknown. Do not conflate with FG-Stress topology.
- FG-116 (https://docs.slatedigital.com/VMR/FG-116.html): documented compression-off setting retains input/output coloration behavior. This gives a controlled test for coloration independent of gain reduction; no exact transfer law claimed.
- TVB product listing https://thevoxbox.shop/pages/plugins establishes a bundled vocal chain, not detector equations. The archived static findings and independent polarity/crest/frequency tests remain separate evidence.
- Evo historical user manual pp. 23–24 (https://www.manuallib.com/download/pdf11/ANTARES-AUTO-TUNE-EVO-USER-MANUAL.PDF; page images inspected): retune setting in milliseconds, zero fast correction, sustained-note humanization, and Natural Vibrato/Targeting Ignores Vibrato described as stochastic optimal linear estimation. This identifies a published method family for vibrato separation, not its state model, coefficients or actual pitch estimator. Independent extension to RetuneControl uses arbitrary explicit duration/ramp/extra-time parameters (default extra time zero). Does not model actual Evo Humanize mapping, does not synthesize audio, and does not implement proprietary vibrato separation.
