## Native stereo delay experiment
Independent C++17 StatefulStereoMod: two fixed 8192-sample double histories (128 KiB total), sample-rate preparation 8–192 kHz, linear fractional-delay reads, shared continuous double phase with adjustable right-channel offset, convex two-channel crossfeed, bounded signed feedback magnitude <=.92, unity-small-signal-slope tanh(drive*v)/drive inside feedback, finite/denormal guard, eight controls smoothed by a 10ms time constant. Center/depth bounds are convex under shared smoothing and delay stays between .25 and 40ms, less than history capacity at maximum rate. Control updates must occur on same owner audio thread; no cross-thread mailbox, no lock-free host parameter bridge. Explicit reset and prepare clear history, ordinary setTarget does not. Not a clone of a vendor plugin, nor the earlier fixture's float32 clock model. Uses deliberate double phase for original long-term clock quality. Feedback color is not oversampled; alias evaluation still needed. Slewed delay can create pitch excursions and should not be mistaken for crossfaded structural switching.
