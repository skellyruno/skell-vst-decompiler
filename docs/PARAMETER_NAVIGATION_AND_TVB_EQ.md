## Parameter navigation
New parameter_xrefs.py locates explicitly requested NUL-terminated ASCII/UTF16LE string substrings, uses bounded RIP-relative LEA byte candidate search, then validates decoded instruction boundaries and destination against one or both decoders in eligible unwind regions. Prioritizes regions with multiple target strings. Recognizes only a conservative direct argument-register call window, clears tracked values on unknown writes/branch/call, and separately recognizes an explicit MSVC call/dereference/float-transfer sequence. No alias analysis or general semantic inference. Optional repeated --parameter argument to existing dsp_job merges navigation with class-guided report, exact source hash check, old UI default unchanged. Reports can be opened in current Analyzer; explicit parameter entry in UI remains future work.
