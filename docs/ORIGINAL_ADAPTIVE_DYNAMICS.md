# Independent adaptive dynamics experiment

This original design is not an attempt to reproduce any commercial compressor. Fast and slow squared peak detectors use time constants 1 and 45 ms. The detector amplitude is sqrt(0.65 fast + 0.35 slow). Soft-knee reduction uses the continuous quadratic knee in dB with slope 1-1/ratio. Positive energy contrast (fast-slow)/(fast+slow+epsilon) interpolates attack time coefficients between 2 and 18 ms; slow relative energy interpolates release between 55 and 240 ms. A single gain is applied to both channels. adapt=0 provides a fixed timing baseline with the same detector and curve. No allocations, locks or I/O in the sample path; log/pow CPU still requires measurement. No true-peak ceiling claim. Timing coefficients are interpolated, not literal time constants. The test uses deterministic steps and randomized samples, not real music or listening approval.
