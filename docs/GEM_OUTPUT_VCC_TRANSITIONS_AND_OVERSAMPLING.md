### Gem Dopamine
At 0x58be76–0x58bee0, one branch adds three buffers to the processed destination (helper 0x5616b0), another writes the sum of two buffers (helper 0x561860). Bounded subtraction and addition helpers operate on 32 float values. Together with the already verified parallel filtering and nonlinear calls, the source shows overlapping signal construction, not proof of a perfectly complementary four-band bank. In particular the pre-processing difference path subtracts the first two filtered buffers; the normal branch adds all three processed filter paths. Do not equate its reconstruction with the original Skell Spectral4 design or infer a complete crossover response.

Both recombination branches converge at 0x58bedb and call 0x553140, a separate in-place sample curve processor. Its mode field selects five cases (0 through 4); code includes signed threshold clipping and quadratic soft-knee sections, plus other transfer variants. Constructor 0x58c010–0x58c0ef supplies mode 1 to the setup helper at 0x5536d0, which writes the selector and associated curve coefficients. The mode-1 branch in 0x55334d–0x5535d4 uses quadratic sections and constant limits outside those sections. This is a constructor default, not proof of the active host setting. The alternate recombination branch is not proven to be a de-esser cue. No raw curve coefficients or proprietary implementation committed. Full parameter setter mapping and response measurements remain unresolved.

### VCC Channel
Eight earlier dispatch targets 0x17feb0, 0x17fed0, 0x17ff70, 0x17ff90, 0x17ffb0, 0x17ffd0, 0x17fff0, 0x180010 subtract a supplied count from state, derive a conditional selector, and dispatch through a two-entry table. First entries resolve to four distinct state-reset routines, second entries share one return-only target 0x176540. Reset helpers write state, two complementary scalar values and a count. These are transition management candidates, not identified saturation cores. This is a correction to the prior interpretation of the outer dispatch triplets; preserve the older report. Other indirect paths, true nonlinear audio kernels, mode labels and host runtime still unverified.
