# Three-track research comparison

Reccmp v0.1.9 is a standalone AGPL-3.0-or-later recompilation comparison tool. Upstream documents old MSVC x86 support and requires a corresponding build and PDB for annotated function comparisons. It does not recover an algorithm automatically, and no matching source/PDB for these private reference products is available. Do not attempt vendor recompilation or use it as a drop-in x64 analyzer. The independent Skell range audit is not a port of reccmp. Standalone owned i386 export smoke verifies matching vs intentionally changed public export names using reccmp-verexp and our own legacy PE counts. This does not establish function similarity.

TVB: 64 archived ranges, 29 recorded region digests. 35 lack a region sha256 field; prioritize provenance completeness and independent authorized measurement of dynamics, dynamic EQ, saturation and spatial response. Keep the original DSP prototypes separate from vendor evidence. VMR: 64 archived ranges (8 FG-116, 50 FG-2A, 6 FG-Stress), all with recorded region digests. This is an imbalance in available evidence, not an estimate of algorithm complexity. Prioritize FG-116 and FG-Stress behavioral probes, attack/release, steady-state gain, tone and stereo linkage. Evo: version 6.0.9 x86 metadata only, no verified DSP ranges. Prioritize independent pitch estimation on noisy and changing tones, voiced/unvoiced decisions, note hysteresis, controlled retune-step experiments and authorized audio comparisons. For all three, use identical source audio and settings, time alignment, loudness matching, held-out material, latency and CPU reporting. No raw reference binaries or audio in CI. No similarity percentage without corresponding validated evidence.

Reproduce archived audit: python -m skell_vst_decompiler.track_audit reports . Save output outside reports unless schema is explicitly classified. Compare hashes only within exact fingerprint and range; recorded digest disagreement is a review flag, not conclusive byte conflict unless digest semantics match.
