# Historical pitch architecture and behavioral DSP experiments

Public primary source: Harold A. Hildebrand, US5973252A, issued October 26, 1999, https://patents.google.com/patent/US5973252A/en . The specification describes initial period detection using reduced-rate autocorrelation/energy testing, a subsequent tracking mode, and time-domain pitch correction by resampling and adding/removing cycles. This is historical disclosed architecture, not proof of the implementation of Evo 6.0.9. No source code or binary equivalence claimed. Secondary contemporary discussion: https://valhalladsp.com/2009/05/21/auto-tune-autocorrelation-and-seismic-analysis/ . Historical documentation describes a different detector family from YIN; the existing YIN baseline is retained.

New historical_pitch_reference.py is independently written offline adjacent-period normalized squared difference (E-2H)/E, using frame-local candidate lags and first qualifying local minimum with interpolation. This is a public mathematical reference, not a port of the patent's whole tracking or resynthesis procedure. No proprietary coefficients, binary-derived code, or production integration. 30 clean/missing-fundamental tests and seeded noise/silence checks; 90 common cases per detector with noise levels 0/.05/.15 and both harmonic sets; report acceptance, rejection, gross errors and absolute cents without hiding failed detections. CI results pending.

TVB and VMR: gain_response.py computes input/output block RMS ratios and least-squares scalar gain plus normalized residual on explicitly aligned offline pairs. fit_relaxation reports descriptive one-pole fit and residual, not inferred code. Validate on known original stereo scaling and exponential recovery. Intended for authorized renders with source hash, sample rate, settings, exact alignment and held-out audio. TVB: independently measure detector/mode, threshold and output coupling, coloration and dynamics. VMR: independently compare FG-116/FG-2A/FG-Stress static gain, attack and recovery at different levels and stereo configurations. Existing atlas remains the source for static findings; no automatic code reconstruction.
