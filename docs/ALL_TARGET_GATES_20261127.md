## Required evidence by family

- Dynamics/gates: calibrated level steps and bursts at multiple frequencies, attack/release, hold, hysteresis, ratio/knee, stereo link, sidechain, transient and level dependence. Separate fit and held-out recordings.
- EQ and color: channel-specific sweeps at several levels, stepped controls, phase and frequency response, harmonic/nonharmonic measurements, overload and sample-rate dependence.
- Clipping/limiting: ceiling, oversampling, aliasing, sample and estimated intersample peak, transient preservation, release and latency.
- Spatial/delay/modulation: independent left/right impulses at several levels, phase and cross-channel response, modulation trajectories, predelay, tempo sync, tail duration and automation transitions.
- Pitch/key: calibrated notes, detune and glide, vibrato, noise, transients, unvoiced segments, retune/formant controls and host latency; real vocal holdout.
- Sidechain masking: fixed main/key identities, frequency/level matrix, independent stereo, matched controls, transient and reverb-tail behavior.
- Host/suites: declared plugin/module identity, version, numeric public parameter IDs where exposed, legal host settings, bypass/dry verification, full tails, exact file hashes, no blind normalization/time shift.

For 80%, require complete documented behavior and control mapping within an explicit supported scope, with unresolved modes clearly excluded. For 100%, require broader real-audio and setting validation; source recovery itself is not the objective. Independent code must stay separate from vendor evidence. No proprietary implementation extraction, activation bypass, arbitrary vendor binary execution, or private media in Git. No production adoption until separate host and sound-quality gates pass.
