## Verified local benchmark
Source experiments/ground_truth/Kernel.cpp contains five original small DSP kernels plus a pass-through negative control. Build 5 training PE32+ DLLs using Clang/LLD 17 -O2/variant0, then 18 test DLLs at -O1/-O3/-O0 with variant1. Export names and signatures are identical; the nearest-reference classifier sees only normalized instruction-count features. GNU and LLVM extraction agreed on every built PE. The fixture's exact exported setter/process RVAs give an independent source answer key; bounded operand checks agreed between both disassemblers. Ten of 15 known holdouts have direct setter/read endpoints at state offset zero, two optimized negative controls have setter but no read, and debug builds are left without direct endpoint confirmation. This is a fixture-specific ABI check, not general C++ object dataflow.

Optimized holdouts: 10/10 known correct, two unknowns abstained. Across all 18: 11/15 known correctly classified, one incorrect debug gain -> filter, three known abstentions, all three unknowns abstained. Precision 11/12=91.7%; known recall 11/15=73.3%. The data are a small development benchmark, not genuinely independent plugin holdout: gain/delay implementations are unchanged between source variants and the same Clang family compiled all PE cases. Do not claim generalization to full JUCE or commercial code. Preserve this baseline including error; next add distinct implementations, MSVC vs Clang/GCC, symbol-stripped full plugins and a frozen unseen plugin set.

Six separate GCC 14.2 Linux native shared-library builds of the same owned source were executed locally for controlled audio probing. Five stimuli: impulse, quiet/loud 1 kHz, quiet 9 kHz, loud-to-quiet recovery. All six expected behavioral categories matched. The clip fixture has no observed recovery difference; the envelope fixture's normalized difference is 0.53305 over the first 64 samples after the level change. Delay control moved onset from 2 to 5 samples. Parameter .25 to .75 changed bytes 2..3 of the known float32 state in all six, but the negative-control audio did not change: state difference alone is not semantic proof. These are native Linux results, not the PE DLLs executed or VST3 captures. See reports/ground_truth/baseline_2026_11_25.json for source and binary hashes, classifications and observed effects. Reproduce full detail with PYTHONPATH=. python tests/ground_truth_smoke.py. Archived local regression suite 88/88 passed including four new unit tests. First fixture link failed due C++ mangled _fltused, fixed with C linkage; early objdump text export parser failed, replaced with checked fixture-specific export directory/ordinal reading. No suppression.

## Analyzer worker
skell_vst_decompiler/analyzer_worker.py adds bounded public normalized parameter inventory/sweeps via existing pinned Pedalboard 0.9.23 and Windows x64 installed adapter. Explicit installed-and-licensed purpose, absolute path, exact bundle and module fingerprints and version required. Fresh child per point plus repeated baseline; refuses unexpected readback/changed source, observes five controlled audio probes and candidate stable state byte spans, flags other changed controls. Temporary raw state is private, never restored, and not emitted in report. Baseline equality and variable-length states are explicit gates. Host-exposed key is NOT numeric VST3 ParamID. Meter/quantized/dynamic controls may reject; actual runtime adapter unverified locally. Process isolation is crash containment, not security sandbox. Keep only trusted authorized installations. Do not automate every vendor control before checking fixture CI.

Example private spec: {"authorization":"installed_and_licensed","purpose":"owned_fixture","path":"C:/path/to/Skell Host Fixture.vst3","sha256":"<exact bundle hash>","version":"1.0.0","sample_rate":48000}

Fingerprint via existing host_capture fingerprint. Then:
python -m skell_vst_decompiler.analyzer_worker inventory private_spec.json
python -m skell_vst_decompiler.analyzer_worker sweep private_spec.json gain 0.25 0.75

Redirect JSON to a private file for the viewer. The new Windows smoke sweeps the existing real owned JUCE gain/delay plugin and tests analyzer audio identity at 64/1024 frames. Local unit tests used mocks for subprocess orchestration, not actual Windows hosting.
