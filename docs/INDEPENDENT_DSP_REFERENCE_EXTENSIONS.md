# Independent DSP reference extensions
- Pitch: exact fixed-window squared difference identity d(tau)=E_ref+E_shift-2*C(tau). FFT convolution calculates correlation and prefix sums calculate shifted energy. Clamp tiny negative roundoff; retain the existing cumulative normalization and first-minimum search. Direct implementation stays default.
- Retune: note selection with hysteresis (12 cents default), periodicity gating (not probability), exponential control with alpha=1-exp(-hop_ms/retune_ms), immediate 0 ms, reset on unvoiced. No pitch synthesis or formant processing.
- Coloration: first-order antiderivative antialiasing of normalized tanh, divided difference of log(cosh(drive*x))/(drive*tanh(drive)), midpoint fallback near equal samples. Low-frequency half-sample delay and high-frequency attenuation mean folded-bin results are not a direct measure of perceptual quality. Offline arrays, not a streaming real-time implementation. Independent reference for TVB/VMR experiments, not a recovered vendor law.
- CI: four unit tests, 30 noisy/clean pitch cases, three timed repeats per backend, coherent 9 kHz synthetic saturation with folded 21 kHz relative-to-fundamental bin and fundamental RMS. Record actual results only after completed CI.
