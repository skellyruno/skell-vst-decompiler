# Independent behavioral discrimination
TVB: equal RMS sine and high-crest pulse, plus dual-mono vs one active channel, separate global peak, mean-channel power and max-channel RMS hypotheses. These are test stimuli/metrics, not recovered detector equations. For actual authorized measurements use aligned renders, same settings and control for attack/release, makeup and distortion. VMR: compare descriptive one- and two-exponential recovery fits on the initial 65% of a measured control series and report later 35% held-out RMSE. Nonnegative amplitudes and fixed 32-point 5–2000 ms grid, known steady level, no circuit identification. Synthetic single/dual controls verify identifiability only under these assumptions. Evo: identical two-second synthetic vibrato, glide and step trajectories with inserted noise-only interval, 65 ms frame/10 ms hop, score both independent detectors at center and explicitly count misses/false positives/gross errors. Windows overlapping voice transitions or large pitch steps excluded and counted, so transition latency is NOT measured. No private reference audio, vendor implementation or sound-quality claims.
